# Harbor for iPhone

A Stremio client for iPhone. In testing.

## Features

- Native screens (UIKit): home, discover, movies, shows, anime, library, title pages, search, Live TV, calendar, downloads, addons and the source picker.
- Native player (VLC) with Dolby / DTS audio, swipe for brightness and volume, and other sources from inside the player.
- Addon subtitles with adjustable size, background, colour, position and delay.
- Downloads that keep going in the background and play offline, with their subtitles.
- Arabic and English.

## Install (testing builds)

Builds are unsigned IPAs: SideStore or AltStore signs them on your phone.

1. Download `harbor-ios.ipa` from the newest build on the [Releases](https://github.com/Sultan-it-1/Harbor-ios-/releases) page.
2. Open it with SideStore or AltStore.

## Building

Actions → **ios-build** → Run workflow. Each build publishes the IPA as a pre-release, with
screenshots of every screen in English and Arabic from the iPhone simulator and the app's log.
